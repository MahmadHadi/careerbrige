# CareerBridge

CareerBridge is a mentorship platform that connects students with industry experts. Students can browse expert profiles, book mentorship sessions, and receive guidance on careers, technology, interviews, and professional growth.

The platform supports three roles:

* **Students** - Discover experts and book sessions.
* **Experts** - Create profiles, showcase expertise, and mentor students.
* **Admins** - Manage users, experts, and platform activities.

## Features

* User authentication and authorization
* Role-based access control
* Expert profile management
* Expert discovery and search
* Mentorship session booking
* Booking management
* Admin dashboard
* Secure REST API
* Request validation and error handling

## Tech Stack

### Frontend

* React.js
* TypeScript
* Tailwind CSS

### Backend

* Node.js
* Express.js
* TypeScript
